# MongoDB 图书馆管理实验
仓库：homework-demo

## 实验内容
任务1：MongoDB服务部署、环境变量
任务2：建库、普通集合、固定集合、时序集合、视图、数据导入
任务3：查询、更新、删除（Q1-Q16、U1-U4、D1-D3）
任务4：聚合管道、索引、用户权限
任务5：PyMongo Python应用开发
任务6：Compass图形化验证、数据导出

## 文件说明
- dataset：实验用到的原始数据集
- pycode：pymongo 开发代码
- report：实验报告文档
- screenshots：实验过程截图
- scripts：mongodb shell脚本

## 运行说明
1. 安装MongoDB，启动服务
2. 导入dataset中的数据
3. 执行scripts脚本或者运行pycode里的python程序
